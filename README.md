# NL2SQL 数据查询系统

> 面向数据仓库的自然语言问数服务（项目展示页 · 代码因涉及企业数据模型暂不公开）

## 项目简介

让业务同学用自然语言直接查询数据仓库，无需写 SQL。基于 LangGraph 构建的 **12 节点工作流**，覆盖「意图理解 → Schema 召回 → SQL 生成 → 校验纠错 → 结果呈现」完整链路。

## 核心架构

```
用户提问 → 意图识别 → 表/字段召回（三路并行）→ SQL 生成
                ↓                              ↓
          澄清追问（低置信度）          SQL 语法/字段校验
                                               ↓
                                   执行 ──失败──→ 纠错重试闭环
                                               ↓
                                    结果可视化 + 自然语言总结
```

## 技术要点

- **12 节点 LangGraph 工作流**：意图识别、多轮澄清、SQL 生成、执行、纠错各司其职，节点间状态显式管理
- **三路并行召回**：表名召回 / 字段召回 / 历史相似问题召回，提升 Schema 定位准确率
- **SQL 校验-纠错闭环**：语法校验 + 字段存在性校验，失败自动携带错误信息重新生成，显著降低幻觉
- **SSE 流式输出**：进度节点实时推送，生成过程可视

## 技术栈

LangGraph · LangChain · DashScope（Qwen）· MySQL/数仓 · FastAPI · SSE
